# TESSERA (테세라) — MVP

> **Every piece finds its place.** 조각이 모여, 설계가 완성된다.

TESSERA는 건축 설계 전 과정을 **노드 그래프**로 조립하는 AI 설계 플랫폼의 MVP입니다.
CAI CANVAS(카이캔버스) 구조 분석에서 도출된 개선점을 반영해,
"캔버스 위에 그리는 도구"가 아니라 **"설계 지능의 조각을 조립하는 스튜디오"**로 재설계했습니다.

## 핵심 개념

### 6개 Tile (구 7-에이전트 재설계)

| Tile | 역할 | 구 CAI CANVAS 대응 | 차별점 |
|---|---|---|---|
| **GROUND** | 대지·법규 브리핑 | PLANNERS + SITE | 결정론적 시드로 같은 주소=같은 브리핑, 법령 인용 태그 |
| **FLOOR** | 파라메트릭 평면 | PLAN | GROUND 한도가 상수로 주입, **확정 전 실시간 법규 적합성 미리보기** |
| **MASS** | 3D 매스 스터디 | SITE 3D | FLOOR와 층고 동기화, stepback 파라미터 |
| **LENS** | 카메라 렌더 | IMAGE + VIEWPOINT | 방위각/고도/렌즈/시각 카메라 그래프, 시각별 스카이 |
| **CUT** | 입면·단면 | 2D DRAWING | ELEVATION 공석을 채움, 절단 유형/축척 |
| **FOLIO** | 보드·리포트 조판 | PRINT + VIDEO | 업스트림 조각 자동 조판 |

### 크로스커팅 레이어 (CAI CANVAS에 없던 것)

- **VERSION DAG**: 모든 생성이 커밋으로 기록되고, 파라미터 스냅샷과 함께
  되돌리기가 가능합니다. "Results in Flow"를 버전 관리로 완성.
- **LEDGER**: 실행 버전에 **예상 크레딧이 먼저 표시**되고(`생성 · 5c`),
  소비 내역이 잔액과 함께 원장에 쌓입니다. 불투명 크레딧 문제의 해법.
- **STALE 마킹**: 업스트림이 갱신되면 다운스트림 타일이 흐려져
  재실행이 필요함을 알립니다.

## 데이터 흐름

```
GROUND ──→ FLOOR ──→ MASS ──→ LENS
              │        └──→ CUT
              └──────────────→ FOLIO
```

- 포트 드래그로 연결 (출력 → 입력), 엣지 클릭으로 해제
- 타일별 입력 타입 검증 (FLOOR는 GROUND만 받음 등)
- `Delete` 키로 선택 타일 삭제

## 기술 노트

- 바닐라 JS + SVG, 의존성 0, 로컬 우선(localStorage 자동 저장)
- 목업 파이프라인은 **결정론적**(mulberry32 시드): 같은 입력 = 같은 결과.
  실서비스에서는 생성 AI 렌더와 규칙 엔진(면적·법규 계산)을 분리하는
  것 이 MVP의 철학을 그대로 확장합니다.
- 프로젝트 JSON 내보내기/가져오기 지원

## 로드맵

- **Phase 1 (MVP, 이 저장소)**: 노드 그래프 + 6 Tile + 버전/원장
- **Phase 2**: 실제 공공데이터 API(VWorld) 연동, 법규 RAG, DXF/IFC 출력
- **Phase 3**: 실시간 협업(CRDT), 팀 좌석, 클라이언트 리뷰 링크
- **Phase 4**: Tile 마켓, 멀티모델 오케스트레이터
